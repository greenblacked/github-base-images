#   pip install --require-hashes --no-deps --only-binary :all: -r az-overrides.txt
# Why they are replaced at all is explained above that RUN.
#
# Exact versions, and the sha256 of every wheel a linux amd64 or arm64
# CPython can pick, as PyPI's JSON API lists them for that release: pip
# refuses anything else. Not edited by hand. scripts/check-pins.sh tracks
# each as its own pin (az-pyjwt, az-cryptography, az-pyopenssl, az-urllib3),
# and scripts/bump-pins.sh rewrites the version and its hashes together, at
# least seven days after the release, on a pin-bump PR. --no-deps because
# these are replacements for packages azure-cli already ships, whose own
# dependencies (cffi for cryptography) it ships too; `pip check` in the
# build fails if that ever stops being true.
